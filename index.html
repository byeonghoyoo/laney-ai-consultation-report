상담 전용 페이지로 이동

홈페이지 버튼에 상담 페이지 주소를 연결합니다. 화면 안에 넣기 어려운 경우 사용할 수 있는 대안입니다.

고객이 상담 페이지로 이동하게 된다는 차이가 있습니다.
‘일반 코드 위젯’과 ‘커스텀 위젯 스튜디오’를 구분해야 합니다.

새 커스텀 위젯 스튜디오는 외부 통신과 iframe 삽입을 지원하지 않는다고 안내합니다. 이번 방안은 일반 코드 위젯 또는 공통 스크립트 삽입 경로를 기준으로 검토했습니다.

Mac 서버에도 접속 주소가 필요합니다.

고객은 병원 내부의 맥 주소로 직접 접속할 수 없습니다. 공개된 HTTPS 주소를 자체 상담 서버에 연결해야 합니다. Cloudflare Tunnel처럼 인터넷 주소와 로컬 서버 사이를 연결하는 방법을 검토할 수 있습니다.

개념상 연결 경로: 고객 브라우저 → 공개 HTTPS 주소 → Mac의 상담 서버. 홈페이지 안에서 직접 통신한다면 해당 홈페이지의 요청을 허용하도록 서버를 설정해야 합니다.

운영 중인 홈페이지의 변경은 별도 단계입니다.

현재는 보고서에 방안을 정리한 상태입니다. 시험 설치 후 PC·모바일과 연결 끊김 상황을 확인한 다음 실제 도입 여부를 판단하시면 됩니다.
