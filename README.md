# 병원 AI 상담 사례와 뷰티블라썸 자체 운영 검토

**[공유용 보고서를 확인하십시오](https://byeonghoyoo.github.io/laney-ai-consultation-report/)**

같은 주소에서 두 탭으로 보고서를 읽으실 수 있습니다. 존대말과 쉬운 설명, 실제 스크린샷 및 클릭형 구성도를 사용했습니다.

## 1. 병원의 실제 AI 도입 사례

연세스타피부과의 상담 화면·공개 코드와 예약 신청 양식을 소개합니다. 문의를 받고 연락처를 확보한 뒤 병원 확인으로 이어지는 흐름을 설명합니다. 내부 운영 성과·계약 요금·사용 모델은 확인되지 않았습니다.

공개 코드에 있는 레이니 연결은 기술 이해를 위한 참고 자료입니다. 업체 소개와 공개 비용 계산기는 펼쳐서 볼 수 있습니다. 연세스타의 실제 계약 금액이나 업체 추천으로 해석하시면 안 됩니다.

## 2. 뷰티블라썸 제로코스트 적용안

기존 아임웹에 고객용 상담창을 넣고, 11월 수령 예정인 Mac Studio에서 자체 상담 서버와 로컬 AI를 운영하는 방안을 검토합니다.

- 고객 화면: 아임웹 일반 코드·공통 스크립트 경로 또는 외부 상담 페이지.
- 답변 처리: 자체 서버가 승인된 병원 자료를 찾아 GLM·DeepSeek 등 후보 모델에 전달합니다.
- 기록 관리: 원본은 자체 PostgreSQL DB에 보관하고 접수 요약은 직원용 Google 스프레드시트로 전달합니다.
- 자동화: 실시간 상담에는 n8n이 필수는 아니며, 후속 업무 자동화가 필요할 때 검토합니다.
- 비용: 추가 상담 구독료와 외부 AI 호출료를 줄이는 구성입니다. 장비·전기·개발·백업·도메인·관리 비용까지 0원이라는 뜻은 아닙니다.
- 도입 순서: 병원 자료 준비 → 장비 수령 후 모델·동시 문의 시험 → 아임웹·DB·시트 연결 시험 → 제한적 운영 검토.

아임웹 코드 삽입 기능과 공개 모델·DB·연결 방식의 공식 자료를 확인했습니다. 우리 사이트의 실설치 호환성, Mac 속도와 24시간 운영 안정성은 미검증입니다. 이번 작업은 보고서 편집이며 실제 상담 시스템은 구축하지 않았습니다.

## 보고서 파일

- `index.html`: 두 보고서의 내용·근거 링크·스크린샷.
- `report.css`, `report.js`: 기존 사례 화면·이미지 확대·유료 비교 계산기.
- `zero-cost.css`, `zero-cost.js`: 탭 전환·자체 운영 구성도·전기 비용 계산기.
- `assets/`: 직접 촬영 화면 6장, 사용자 제공 화면 1장과 아이콘.
- `QA.md`: 검증 결과와 확인 범위.
