## 2. 참고 홈페이지의 상담창은 어떻게 연결되어 있나요?

[연세스타피부과 참고 페이지](https://www.yonseistar.co.kr/ko/condition/self-harm-scar)의 공개 JavaScript에서 레이니 서버 주소와 외부 상담 API 경로를 확인했습니다. 채팅 기능에는 병원 식별 정보와 언어 설정을 전달하는 구성이 있습니다. [확인한 공개 코드](https://www.yonseistar.co.kr/_next/static/chunks/0.._d5~zdymhr.js)

**코드에 나타난 연결 구조**는 다음과 같습니다.

> 고객이 홈페이지에 질문 입력 → 레이니 서버로 전달 → 답변을 홈페이지 채팅창에 표시

따라서 공개 코드 기준으로는 **외부 서버와 연결하는 방식**입니다. 병원 PC에서 AI가 실행되는 구성이라는 근거는 확인하지 못했습니다.

다만 이번 조사에서는 실제 고객 상담을 전송하지 않았습니다. 실제 상담 요청의 성공 여부, 서버 내부 설정과 사용 AI 모델은 확인되지 않았습니다. 사용자의 ChatGPT 구독을 연결하는 상품인지도 이 코드만으로 판단할 수 없습니다.

## 8. 아임웹 직접 연동이 어려우면, 외부 팝업으로 만들 수 있나요?

**네. 별도 상담 페이지를 외부 서버에 만들고 아임웹에서 여는 방식은 구현 대안입니다.** 아래 내용은 공개 기술 문서를 바탕으로 한 설계 검토이며, 레이니와의 연결이 검증된 완성 상품은 아닙니다.

예를 들어 Vercel에 상담 화면과 서버 기능을 운영하고, 아임웹에는 상담 버튼과 팝업을 여는 코드만 넣을 수 있습니다. Vercel은 서버에서 API 요청을 처리하는 Functions 기능을 제공합니다. [Vercel 서버 기능 안내](https://vercel.com/docs/functions) · [아임웹 코드 삽입 안내](https://www.imweb.me/qna?mode=faq&q=71387)

> 아임웹 메인 화면 → 화면 안의 상담 팝업 → Vercel의 상담 페이지 → 업체가 허용한 AI 상담 연결

| 방식 | 고객에게 보이는 모습 | 확인할 조건 |
|---|---|---|
| 홈페이지 안에 팝업 표시 | 원래 홈페이지 위에 상담창이 겹쳐 열립니다. | 아임웹 코드 실행과 외부 페이지 삽입이 허용되어야 합니다. |
| 버튼 클릭 후 새 창·탭 | 상담 전용 페이지가 따로 열립니다. | 사용자의 클릭과 상담 페이지 주소가 필요합니다. |
| 버튼 클릭 후 같은 탭 이동 | 상담 전용 페이지로 이동합니다. | 별도 페이지 안의 상담 기능이 정상 작동해야 합니다. |

### 방문 즉시 자동으로 띄우는 것도 가능한가요?

**홈페이지 화면 안의 팝업**은 메인 페이지를 방문했을 때 표시하도록 설계할 수 있습니다. 반면, **별도 브라우저 창을 자동으로 여는 방식**은 브라우저의 팝업 차단 정책 때문에 모든 방문자에게 보장할 수 없습니다. 새 창을 이용한다면 고객이 상담 버튼을 누른 직후 여는 방식이 적합합니다. [브라우저 팝업 정책](https://developer.mozilla.org/en-US/docs/Web/API/Window/open)

### 외부 팝업으로 해결되는 범위

아임웹 안에서 상담 기능 전체를 실행하지 않아도 되는 장점이 있습니다. 다만 아임웹 자체가 코드 실행이나 외부 페이지 삽입을 제한한다면 화면 안의 팝업 방식도 영향을 받습니다. 이때는 상담 페이지로 이동하는 일반 링크 방식을 검토할 수 있습니다.

외부 페이지를 홈페이지 안에 넣으려면 해당 페이지의 삽입 정책도 허용되어야 합니다. 서버의 보안 설정이 삽입을 막으면 팝업 안에 표시되지 않습니다. [외부 페이지 삽입 정책](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors)

**레이니의 연결 조건은 그대로 확인해야 합니다.** 업체가 상담 페이지나 외부 연결용 API를 제공해야 하며, 홈페이지에서 발견한 API 주소만으로 다른 병원이 서비스를 사용할 수는 없습니다. Vercel에 화면을 만든다고 해서 레이니의 사용 권한과 예약 연동이 자동으로 생기는 것도 아닙니다.

별도 개발을 선택하면 개발·운영·호스팅 비용이 추가될 수 있습니다. 실제 구성에 따라 달라지므로 이 보고서의 레이니 예산에는 포함하지 않았습니다.

Vercel의 무료 Hobby 요금제는 개인의 비상업적 용도로 제한됩니다. 병원 운영용 상담 서비스를 만들 때는 상업적 이용이 가능한 요금제를 예산에 반영하셔야 합니다. [Vercel 무료 요금제 이용 범위](https://vercel.com/docs/plans/hobby)

### 조사 범위

레이니와 아임웹의 공개 공식 자료, 참고 홈페이지의 공개 코드를 조사했습니다. 업체의 직접 답변, 실제 아임웹 설치, 고객 상담 전송과 예약 접수는 이번 조사에 포함되지 않았습니다. 확인되지 않은 항목은 보고서에 명시했습니다.
